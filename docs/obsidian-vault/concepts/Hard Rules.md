# Hard Rules

- **No copyrighted content** in the repo or builds — no lyric text anywhere, lyrics
  cached only at runtime, evaluation audio downloaded to temp dirs (AGENTS.md).
- **Privacy** — no telemetry; only public title/artist + raw audio leave the machine;
  never commit personal data (`metrics.json`, `settings.json`, tokens).
- **Verify, don't guess** — destructive actions need strong evidence.

Codified in `.specify/memory/constitution.md` ([[Spec Kit]]).
