# Lyric Immersion and Karaoke

A transparent, always-on-top karaoke overlay: it reads what is playing ([[Media Sources]]),
finds and verifies synced lyrics ([[Lyric Sourcing]]), keeps them in time with the audio
([[Sync Engine]]), and renders them with furigana / romaji / pinyin / romaja + English.
