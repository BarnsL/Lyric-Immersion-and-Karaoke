# Lyric Immersion — Obsidian vault

Open **this folder** (`docs/obsidian-vault`) as a vault in Obsidian (*Open folder as
vault*). Start at [[Lyric Immersion]] or open the mind map `Lyric Immersion.canvas`.

- `concepts/` — how this project works (modules, pipelines, the concert subsystem).
- `shared/` — technologies and practices other projects also use. Each note has a
  stable, project-neutral name ([[faster-whisper]], [[PyAV]], [[Shazam]], [[yt-dlp]],
  [[Spec Kit]], ...). When another project's vault links a note of the same name, the
  two mind maps meet there. Copy or link these notes into a shared vault to join them.

Machine-local Obsidian state (`.obsidian/`) is git-ignored. Notes contain no lyric
text (see [[Hard Rules]]).
